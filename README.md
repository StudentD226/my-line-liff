ระบบสารสนเทศเพื่อบริหารจัดการค่าส่วนกลางและติดตามหนี้ค้างชำระ
เป็นโครงงานที่จัดทำขึ้นในปีการศึกษา 2569 โดยนางสาวมัณฑนา งามสันเทียะ และนายอภิวิชญ์ ต้นศรี โครงงานนี้พัฒนาระบบสำหรับการบริหารจัดการค่าส่วนกลางให้แก่นิติบุคคลและลูกบ้าน มีฟีเจอร์หลักในการชำระค่าส่วนกลาง การออกใบแจ้งหนี้ การติดตามหนี้ และระบบแจ้งซ่อม โดยพัฒนาด้วย React, Next.js, Node.js, PostgreSQL ร่วมกับ LINE OA ตามแนวคิด Agile (Scrum Framework)
